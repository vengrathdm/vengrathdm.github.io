# Artwork drop zone

Add the optional WebP assets here when ready. The site currently renders without them.

| Filename | Suggested ratio | Intended use |
|---|---:|---|
| `hero-world.webp` | 16:9 or 3:2 | Wide atmospheric campaign key art; strange world/planet over a dark sea, no lettering |
| `character-mara.webp` | 3:4 | Portrait of Mara Vell, reluctant human diviner |
| `character-brindle.webp` | 3:4 | Portrait of Brindle Thatch, halfling swashbuckler |
| `character-orryx.webp` | 3:4 | Portrait of Orryx, dragonborn warlock |
| `character-calyx.webp` | 3:4 | Portrait of Sister Calyx, tiefling cleric |
| `map-parchment.webp` | 16:9 | Aged fantasy map parchment / texture, without labels |
| `section-intro.webp` | 3:1 | Optional decorative title plate for Intro |
| `section-postaci.webp` | 3:1 | Optional decorative title plate for Characters |
| `section-kronika.webp` | 3:1 | Optional decorative title plate for Chronicle |
| `section-mapa.webp` | 3:1 | Optional decorative title plate for Map |
| `section-notatki.webp` | 3:1 | Optional decorative title plate for Notes |
| `section-status.webp` | 3:1 | Optional decorative title plate for Status |

No text should be baked into the artwork; headings and labels are rendered by the site.
