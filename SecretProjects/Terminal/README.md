# DOMINION // Terminal kampanii

Polskojęzyczny prototyp systemu operacyjnego kampanii. Otwórz `index.html` bezpośrednio albo przez GitHub Pages.

Projekt jest zaprojektowany jako aplikacja statyczna: nie wymaga Node.js, bundlera ani serwera API. Dane robocze są przechowywane lokalnie w przeglądarce, a pełny model można eksportować i importować jako JSON.

Główna zasada: DOMINION nie jest wiki kampanii ze skórką science-fiction. Jest terminalem operacyjnym, w którym świat kampanii jest trwałym modelem danych, a ekrany są jego wyspecjalizowanymi widokami.
