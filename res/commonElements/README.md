# Common elements

Reusable visual components live here as small, independently includable CSS files.

- `vengrath-button.css` — Vengrath/home button.
- `youtube-playlist-button.css` — YouTube playlist button.
- `pdf-button.css` — PDF button.
- `sound-player.css` + `sound-player.js` — sticky play/pause/mute control with session playback state.
- `common.css` — convenience stylesheet importing the individual components.

Use root-relative resource paths so the same component can be included from any `/p/...` page.
