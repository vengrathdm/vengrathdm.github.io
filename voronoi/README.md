# Voronoi\n\n`voronoi.js` contains the reusable Voronoi geometry and shard-shaping engine used by the site. It does not read page data or manipulate the DOM. `generate(sites, bounds, options)` accepts optional overrides; without them it preserves the homepage behaviour.\n\n`main_voronoi.json` is the homepage data source. `mypaintings2026_voronoi.json` is the data source for `/p/mypaintings2026/`.\n
